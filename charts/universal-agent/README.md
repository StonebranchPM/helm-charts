# universal-agent

Unified Helm chart for Stonebranch Universal Agent (OMS + UAG + UDM). Platform differences (AKS/Istio, OpenShift/Route, native) are selected via the `platform` value — no chart forking required.

![Version: 1.5.1](https://img.shields.io/badge/Version-1.5.1-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 7.9.0.0](https://img.shields.io/badge/AppVersion-7.9.0.0-informational?style=flat-square)

## Usage

```bash
helm repo add stonebranchpm https://stonebranchpm.github.io/helm-charts
helm show values stonebranchpm/universal-agent > my-values.yaml
# Edit my-values.yaml, then:
helm install my-ua stonebranchpm/universal-agent -f my-values.yaml
```

## Platform selection

Set `platform` to one of `aks`, `openshift`, or `native`.

| Platform | Networking | Identity |
|---|---|---|
| `aks` | Istio Gateway + VirtualService (when `istio.enabled=true`) | Azure Workload Identity |
| `openshift` | OpenShift Route + SNI ConfigMap | N/A |
| `native` | ClusterIP Service | N/A |

## Image pull secrets

Create your pull secret separately, then reference it:

```bash
kubectl create secret docker-registry my-pull-secret \
  --docker-server=registry.example.com \
  --docker-username=user --docker-password=token

helm install my-ua stonebranchpm/universal-agent \
  --set 'imagePullSecrets[0].name=my-pull-secret'
```
