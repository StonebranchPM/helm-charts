# universal-controller

Unified Helm chart for Stonebranch Universal Controller (UC) + OMS Agent. Platform differences (AKS/Istio, OpenShift/Route, native/Ingress) are selected via the `platform` value. Requires a customer-supplied UC image and an external database — no bundled database.

![Version: 1.5.0](https://img.shields.io/badge/Version-1.5.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 7.9.0.0](https://img.shields.io/badge/AppVersion-7.9.0.0-informational?style=flat-square)

## Usage

```bash
helm repo add stonebranchpm https://stonebranchpm.github.io/helm-charts
helm show values stonebranchpm/universal-controller > my-values.yaml
# Edit my-values.yaml, then:
helm install my-uc stonebranchpm/universal-controller -f my-values.yaml
```

## Platform selection

Set `platform` to one of `aks`, `openshift`, or `native`.

| Platform | Networking | Secrets |
|---|---|---|
| `aks` | Istio Gateway + VirtualServices | Azure Key Vault CSI (optional) |
| `openshift` | OpenShift Routes | Kubernetes Secret or `credentials.existingSecret` |
| `native` | K8s Ingress / StatefulSet opt-in | Kubernetes Secret or `credentials.existingSecret` |

## Database configuration

Preferred (structured):

```yaml
database:
  host: mysql.example.com
  port: 3306
  name: uc_db
  type: mysql
  user: ucadmin
  existingSecret: my-db-secret   # key: password
```

## Credentials / existingSecret

For production, supply a pre-created Secret and reference it:

```yaml
credentials:
  existingSecret: my-uc-passwords
  # Secret must contain: password, password-keystore, password-truststore,
  # UC_TRUSTMANAGER_TRUSTSTORE_PASSWORD_ENCRYPTED
```

## Image pull secrets

Create your pull secret separately, then reference it:

```bash
kubectl create secret docker-registry my-pull-secret \
  --docker-server=registry.stonebranch.com \
  --docker-username=user --docker-password=token

helm install my-uc stonebranchpm/universal-controller \
  --set 'imagePullSecrets[0].name=my-pull-secret'
```
